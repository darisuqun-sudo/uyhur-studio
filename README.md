# ئاقىل سەھنە (Aqil Hub) — كۆپ ئىقتىدارلىق سۈنئىي ئىدراك سۇپىسى

ئۇيغۇرچە ۋە كۆپ تىللىق كەسپىي سۈنئىي ئىدراك سۇپىسى. **OpenRouter** ۋە **Google Gemini 3.8 Flash** تېخنىكىسى ئاساسىدا قۇرۇلغان.

---

## 🌟 سۇپىدىكى 9 چوڭ ئاساسلىق ئىقتىدار

1. 💬 **ئاقىل پاراڭ (AI Chat)** — كۆپ خىل رول ۋە چوڭقۇر پىكىرلىشىش.
2. 🌐 **ئەقلىي تەرجىمە (Smart Translation)** — ئۇيغۇرچە، ئىنگىلىزچە، تۈركچە، ئەرەبچە ۋە خەنزۇچە.
3. 📄 **ھۆججەت ۋە كۆرۈش سېزىمى OCR (Vision Document Reader)** — رەسىم، كىتاب بېتى ۋە پۈتۈكلەردىن تېكىست ئېلىش.
4. ✍️ **ئەقلىي يېزىقچىلىق ۋە ئىملا (AI Writing & Grammar)** — ئۇيغۇرچە ئىملا تۈزىتىش، ماقالە ۋە ئۇسلۇب پىششىقلاش، ULY لاتىنچە ئالماشتۇرۇش.
5. 📢 **ماركېتىنگ ۋە ئىلان ئىجادىيىتى (Marketing & Viral Copy)** — TikTok، Instagram ۋە تور دۇكانلىرى ئۈچۈن سېتىش قېلىپلىرى.
6. 🎙 **ئاۋازنى يېزىققا ئايلاندۇرۇش (STT)** — نەق مەيدان مىكروفون ۋە ئاۋاز ھۆججەتلىرىنى تېكىستكە چىقىرىش.
7. 🔊 **تېكىستنى ئاۋازغا ئايلاندۇرۇش (TTS)** — تەبىئىي ئاۋاز بىلەن ئوقۇش ۋە `.wav` چۈشۈرۈۋېلىش.
8. 🎬 **مەھسۇلات ئېلان فىلىمى سېنارىيەسى (Ad Video / Human-free)** — ئادەمسىز، كەسپىي ماتېرىيال ۋە كىنولۇق سىن لايىھەسى.
9. 🎨 **رەسىم ھاسىللاش (Image Studio)** — كۆپ خىل نىسبەت ۋە سەنئەت ئۇسلۇبلىرى.

## 🚀 Vercel ئارقىلىق تورغا چىقىرىش ۋە مەخسۇس تور نامى (Custom Domain) ئۇلاش

### 1-قەدەم: كودنى GitHub قا يوللاش
```bash
git add .
git commit -m "Production release"
git remote add origin https://github.com/ھېساباتىڭىز/aqil-hub.git
git push -u origin main
```

### 2-قەدەم: Vercel دا بىر كۇنۇپكا بىلەن چىقىرىش
1. [vercel.com](https://vercel.com) غا كىرىپ GitHub ھېساباتىڭىز بىلەن تىزىملىتىڭ.
2. **"Add New..."** -> **"Project"** نى بېسىڭ.
3. تىزىملىكتىن مەزكۇر قۇرۇلۇشنى تاللاپ **"Import"** نى چېكىڭ.
4. **Environment Variables** بۆلىكىگە تۆۋەندىكىلەرنى قوشۇڭ:
   - `OPENROUTER_API_KEY`: OpenRouter ئاچقۇچىڭىز
   - `GEMINI_API_KEY`: Google Gemini ئاچقۇچىڭىز
5. **"Deploy"** كۇنۇپكىسىنى بېسىڭ. 1 مىنۇت ئىچىدە پۈتۈن دۇنيا زىيارەت قىلالايدىغان تور بېكەت تەييار بولىدۇ!

### 3-قەدەم: ئۆزىڭىزنىڭ مەخسۇس تور نامىنى (Custom Domain) ئۇلاش
1. Vercel باشقۇرۇش كۆزنىكىدىن پروژېكتىڭىزنىڭ **Settings -> Domains** بېتىگە كىرىڭ.
2. ئۆزىڭىز سېتىۋالغان تور نامىنى يېزىڭ (مەسىلەن: `aqilhub.com` ياكى `ai.sizningtor.com`).
3. تور نامىنى سېتىۋالغان شىركەتنىڭ DNS تەڭشىكىگە كىرىپ تۆۋەندىكى ئىككى قۇرنى قوشۇڭ:
   - **Type**: `A`, **Name**: `@`, **Value**: `76.76.21.21`
   - **Type**: `CNAME`, **Name**: `www`, **Value**: `cname.vercel-dns.com`
4. ساقلىغاندىن كېيىن Vercel بىر نەچچە مىنۇت ئىچىدە ھەقسىز SSL (HTTPS) گۇۋاھنامىسىنى ئۆزى ئاپتوماتىك قاچىلاپ، بېكىتىڭىزنى تور دۇنياسىغا ئاچىدۇ!
