# ئاقىل سەھنە (Aqil Hub) — 2 تىللىق سۈنئىي ئىدراك تور بېكىتى

پىلان ھۆججىتى (`torbiket pilan.md`) ئاساسىدا پۈتۈنلەي قۇرۇپ چىقىلغان، **OpenRouter** ۋە **Google Gemini** مودېللىرىنى تولۇق قوللايدىغان زامانىۋى سۈنئىي ئىدراك سۇپىسى.

---

## 🌟 ئاساسلىق ئالاھىدىلىكلەر

1. **ھەر بىر تۈرگە ئايرىم مودېل تاللاش ئىقتىدارى**:
   - **پاراڭ بوت (Chat)**: `google/gemini-2.5-flash`, `google/gemini-2.5-pro`, `claude-3.5-sonnet`, `gpt-4o` ياكى خالىغان OpenRouter مودېلى.
   - **تەرجىمە (Translate)**: ئۇيغۇرچە، ئىنگىلىزچە، تۈركچە، ئەرەبچە ئارىسىدا تەبىئىي تەرجىمە قىلىش ئۈچۈن مەخسۇس مودېل.
   - **رەسىم (Image Studio)**: `FLUX.1 Schnell`, `FLUX.1 Dev`, `Google Imagen 3`, `Stable Diffusion 3.5`.
   - **ئاۋاز (TTS)**: تېكىستنى ئاۋازغا ئايلاندۇرۇش ماتورى ۋە فونېتىك ئەلالاشتۇرۇش.
   - **مەھسۇلات ئىلانى (Ad Video)**: `Gemini 2.5 Pro`, `Veo 2`, `Kling`, `MiniMax` فىلىم سېنارىيە مودېلى.
   - **ئىختىيارىي كود (Custom Model ID)**: OpenRouter دىكى ھەرقانداق يېڭى مودېل نامىنى بىۋاسىتە كىرگۈزۈپ ئىشلىتىش ئىقتىدارى بار.

2. **5 چوڭ ئىقتىدار بۆلىكى**:
   - 🖼 **رەسىم ھاسىل قىلىش**: كۆپ خىل نىسبەت (`1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`), ئۇسلۇب تاللاش، ئۇيغۇرچە تەسۋىرنى ئىنگىلىزچىگە ئاپتوماتىك كۈچەيتىش ۋە چۈشۈرۈش.
   - 🌐 **ئەقلىي تەرجىمە**: ئۇيغۇرچە ↔ ئىنگىلىزچە ↔ تۈركچە ↔ ئەرەبچە ↔ خەنزۇچە، 7 خىل رول (رەسمىي، بەدىئىي، ئىلمىي، سودا، كۈندىلىك)، تىلنى ئاپتوماتىك بايقاش ۋە ئاۋاز چىقىرىپ ئوقۇش.
   - 🎙 **ئاۋازلىق ئوقۇش (TTS)**: ئەر/ئايال، مۇلايىم، خەۋەرچى ئاۋازلىرى، سۈرئەت تەڭشىگۈچ، مۇزىكا پىلاستىنكىسىدەك ئاڭلاش ۋە `.wav` چۈشۈرۈش.
   - 🎬 **مەھسۇلات ئىلان تەشۋىقات فىلىمى**: **ئادەم چىرايى/بەدىنى چىقماسلىق كاپالىتى تولۇق قوغدالغان**. مەھسۇلات رەسىمىنى چۈشىنىپ، 3-4 كۆرۈنۈشلۈك كامېرا، يورۇقلۇق ۋە ئىككى تىللىق ئاۋاز سېنارىيەسى تۈزۈپ بېرىدۇ.
   - 💬 **ئاقىل پاراڭ بوت**: كۆپ نۆۋەتلىك پىكىرلىشىش، رول ئالماشتۇرۇش (ياردەمچى، تەرجىمان، ئوقۇتقۇچى، يازغۇچى).

3. **2 تىللىق ۋە زامانىۋى كۆرۈنمە يۈز**:
   - ئۇيغۇرچە (`ug`, RTL — ئوڭدىن سولغا) ۋە ئىنگىلىزچە (`en`, LTR).
   - قاراڭغۇ (Dark) ۋە يورۇق (Light) تېما ئالماشتۇرغۇچ.
   - تارىخ (History) بەت بۆلىكىدە ئەسەرلەر ساقلىنىدۇ ۋە كۆچۈرۈۋالغىلى بولىدۇ.

---

## 🚀 قوزغىتىش ئۇسۇلى

تۆۋەندىكى بۇيرۇق ئارقىلىق تەرەققىيات مۇلازىمېتىرىنى باشلاڭ:

```bash
npm run dev
```

ئاندىن تور كۆرگۈچىڭىزدە تۆۋەندىكى ئادرېسنى ئېچىڭ:
```
http://localhost:3000
```

مەھسۇلات مۇھىتى ئۈچۈن قوزغىتىش:
```bash
npm start
```
